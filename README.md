# SkillUp Data – Dynamic Programming

## Objetivo
Analisar e ordenar dados de profissionais de acordo com seu nível de qualificação, utilizando **Merge Sort** e **programação funcional** em Python.

---

## Estruturas utilizadas
- Função dentro de função (`merge_sort` dentro de `analisar_profissionais`)
- Ordenação de dados (Merge Sort)
- Estrutura tabular com `pandas.DataFrame`
- Relatório final de resultados
- 20 diferentes informações simuladas

---

## Tecnologias
- Python 3.10+
- Biblioteca pandas

---
